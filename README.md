# Sangam & Curve Scorecard

Monthly sales and collection target vs achievement for **Alcove Sangam** and **The Curve**, prepared for the Steering Committee.

| Month | Dashboard | Source workbook |
|---|---|---|
| October 2026 (reviews Sep 2026, sets Oct 2026 targets) | [2026-10/index.html](2026-10/index.html) | Sangam, Curve Consolidated Target vs Achievement Sales and Collection OCTOBER 2026.xlsx |

## Viewing
Open the live page on GitHub Pages, or download a month's `index.html` and open it in any browser. Each month is a single self-contained file.

## Updating
All figures are in the `DATA` block at the top of the `<script>` in each month's `index.html`. Copy the latest month's folder to a new one (e.g. `2026-11/`), update the figures, and point the root `index.html` at it.
