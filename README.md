|---|---|---|

## Viewing
Download the month's `index.html` and open it in any browser. It is a single self-contained file.

## Updating
All figures are in the `DATA` block at the top of the `<script>` in each month's `index.html`. Copy the latest month's folder to a new one (e.g. `2026-11/`) and update the figures.
